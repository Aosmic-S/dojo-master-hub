# Project Memory

## Core
Professional martial arts aesthetic: deep red, black, and gold color palette.
Typography: Oswald headings, Inter body text. Never serif.
Footer must include "made by Aosmic Studio" attribution.
Roles: Admin (Sensei) and Student. Admin creates accounts; no self-registration.
Student login uses Roll No + DOB (synthetic email under the hood). Admin uses email + password.
